A one-line 1-star review written by a houseplant about its human owner — a sharp
plant's-eye grievance about inconsistent watering, told with a surprising turn:
the human waters the plant like a rumor, once and dramatically, then forgets it
exists until its leaves file a formal complaint.

The program writes the review to `/output/entry.txt`.
